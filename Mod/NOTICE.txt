ISORIM VTOL - Airframe & Armament, test candidate R1.

Uses the native Vehicle Framework upgrade/material/turret APIs and optional FPS Aerial integration.
Original airframe definitions belong to Vanilla Vehicles Expanded.
Models and runtime integration in this package come from the ISORIM team's existing local VTOL assets.
This package contains no Vehicle Framework, VVE, IsoRim, Combat Extended or FPS Bridge DLLs.
The promotional cover is AI-generated. Offline render gallery images are labeled accordingly.
